# Obsidian-Vorlage für das Projekt Cockpit

Diese Dateien gehören in den Vault unter `D:\Vault\Projects\Cockpit\`.
Die Cloud-Session konnte `D:\` nicht erreichen, deshalb liegen sie hier.

## Übertragen (am besten die lokale Claude-Code-Session machen lassen)
1. Ordner `Cockpit/` nach `D:\Vault\Projects\Cockpit\` kopieren.
2. **Rot im Dateibaum:** `cockpit-rot.css` nach `D:\Vault\.obsidian\snippets\` kopieren,
   dann in Obsidian: Einstellungen → Darstellung → CSS-Snippets → `cockpit-rot` einschalten.
3. **Rot im Graph:** Graph-Ansicht öffnen → Filter-Symbol → Gruppen → „Neue Gruppe“:
   Suche `path:Projects/Cockpit`, Farbe Rot.
4. Im Vault-Repo committen.
